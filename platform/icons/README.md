# icons

The one icon set for every app. Each entry in `icons.json` is the inside of a 24 by 24 SVG, drawn in
`currentColor`, with the pack it came from. Most are Remix Icon, and the rest come from IBM Carbon,
Tabler, Hugeicons and Phosphor where those matched best. See `THIRD-PARTY.md`.

`platform/tools/make_icons.py` writes each family's copy. Change the list here, never a copy.
