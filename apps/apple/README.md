# apple

SwiftUI apps for iPhone, iPad and Apple TV, with AVPlayer. It also covers Apple Vision Pro.

Part of an open video platform. Status: written, built by hand. 10,994 lines of Swift in 75 files, a
phone surface and a television surface behind this family's ports. `./check` holds it to those ports
and compiles the generated `Contract.swift` where swiftc is present, but it does not build the app
and there are no unit tests yet. The root README's status table carries this line for every
platform.
