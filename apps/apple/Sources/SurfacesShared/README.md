# Shared by every Apple surface

The brand's colours and font (`Theme.swift`), pictures and icons (`Art.swift`), the reference unit
(`Measure.swift`), the brand's corners (`BrandShape.swift`, written by `write-brand.py`, ignored by git),
words, digits and plural forms. The TV (`SurfacesTV`) and the phone and tablet (`SurfacesPhone`)
surfaces both re-export this module. Android's twin is `apps/android/surfaces/shared`.
