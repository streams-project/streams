# android

Compose apps for Android phones, tablets, Android TV and cars, with Media3.

Part of an open video platform. Status: written, built by hand. 14,906 lines of Kotlin in 93 files,
with Compose screens behind this family's ports. `./check` holds it to those ports but does not run
gradle, and there are no unit tests yet. The root README's status table carries this line for every
platform.
